# Data Dictionary
| Field                   | Meaning                                  |
| ----------------------- | ---------------------------------------- |
| Call Failure            | Number of call failures                  |
| Complains               | 0 = no complaint, 1 = complaint          |
| Subscription Length     | Total months of subscription             |
| Charge Amount           | Ordinal value from 0 lowest to 9 highest |
| Seconds of Use          | Total seconds of calls                   |
| Frequency of use        | Total number of calls                    |
| Frequency of SMS        | Total number of text messages            |
| Distinct Called Numbers | Number of distinct called numbers        |
| Age Group               | Ordinal group from 1 younger to 5 older  |
| Tariff Plan             | 1 = pay as you go, 2 = contractual       |
| Status                  | 1 = active, 2 = non-active               |
| Customer Value          | Calculated customer value                |
| Churn                   | 0 = non-churn, 1 = churn                 |
